Connect to Plaid's sandbox​

For testing only, you'll follow the process that your customers normally use to authorize a connectionConnection A link between a Codat company and a data source (like an accounting platform). Each connection represents authorized access to pull or push data from that platform. to their bank account.

  1. Copy the linkUrl value into your browser, which takes you to Plaid's sandbox.

A message at the bottom of the screen confirms that you're in sandbox mode.

  1. Select Continue.
    A dialog box shows a list of available bank accounts that have sample data for testing. This is Plaid's secure linkLink The authorization flow that allows end users to connect their accounting, banking, or commerce platforms to your application via Codat. site.
  2. Select the bank account type you're interested in, or if it's not listed, search for it first.
  3. Select Continue to Bank Name.
    You will either be directed to log in with sample test credentials or to authenticate for the sandbox.
  4. Enter the test credentials or select Grant Access.
  5. Wait until a confirmation page is displayed.

You're now ready to start testing.
